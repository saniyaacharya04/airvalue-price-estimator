# AirValue – Airbnb Price Estimator

AirValue is an end-to-end machine learning system that predicts Airbnb listing prices using real-world data from the **Inside Airbnb New York City dataset**.
The project demonstrates full ownership of the ML lifecycle: data ingestion, feature engineering, model training, API-based inference, authentication, persistence, freemium feature gating, frontend integration, and automated end-to-end testing.

This repository is designed to reflect a **real internal ML product**, not a tutorial or toy demo.

---

## Problem Statement

Airbnb hosts often struggle to price their listings competitively. Overpricing reduces occupancy, while underpricing reduces revenue. Pricing decisions depend on multiple factors such as location, amenities, and property characteristics, making manual estimation unreliable.

AirValue addresses this by providing:

* A machine learning–based price prediction
* A simple web interface for hosts
* A backend API suitable for integration into larger systems

## Dataset

* Source: Inside Airbnb – New York City
* Type: Detailed listings dataset
* Columns: 79
* Key features used:

  * Bedrooms
  * Bathrooms
  * Amenities (engineered score)
  * Geolocation (engineered score)

The dataset is **not committed** to the repository to ensure data hygiene.

---

## Model Training

The ML model is trained offline using real Airbnb data.

### Feature Engineering

* Price cleaning (`$`, commas removed)
* Bathroom normalization
* Amenities converted to numeric score
* Location score derived from latitude and longitude normalization

### Model

* RandomForestRegressor
* 300 estimators
* Depth capped to prevent overfitting

### Performance

* Test R² ≈ **0.49**
* This is expected and realistic given the noisy nature of real-world pricing data.

## Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/<your-username>/airvalue.git
cd airvalue
```

### 2. Create Environment

```bash
conda create -n airvalue-py310 python=3.10
conda activate airvalue-py310
```

### 3. Install Dependencies

```bash
make install
```

### 4. Configure Environment

```bash
cp .env.example .env
```

---

## Train the Model

Requires the Inside Airbnb detailed `listings.csv` placed at:

```
backend/data/listings.csv
```

```bash
make train
```

Model artifact is saved to:

```
backend/artifacts/airvalue_model.joblib
```

## Failure Modes and Handling

* Missing model artifact → startup failure with clear error
* Invalid JWT → 401 Unauthorized
* Premium access without upgrade → 402 Payment Required
* Missing features → request validation error
* Database unavailable → startup failure

---

## Trade-offs and Design Decisions

* Chose RandomForest for interpretability and robustness
* Limited feature set to avoid overfitting
* SQLite used for simplicity and portability
* Premium logic intentionally stubbed to simulate SaaS design
